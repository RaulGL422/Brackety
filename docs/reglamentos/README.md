# Reglamentos

Cada reglamento oficial se guarda como plantilla de deporte en un MD propio y como datos de puntuación en el módulo `puntuacion`.

| Reglamento | Archivo | Estado |
|---|---|---|
| Liga Yoseikan Budo Andalucía 2027 | `yoseikan-2027.md` | Transcrito; faltan datos (ver pendientes) |

## Reglas generales
- La regla se fija por **modalidad + fase + categoría**; el organizador no la altera una vez publicado el evento.
- El PDF del reglamento puede adjuntarse al evento y se abre desde la pantalla de marcador.
- Los reglamentos son fuente de los tests de puntuación (`04-testing.md`).
- Otras plantillas (judo, karate, taekwondo, fútbol…) se añaden aquí cuando se investiguen.
